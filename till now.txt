📌 Developer Rules

All DB queries → PDO prepared statements (no raw mysqli)

Protected pages check $_SESSION['user_id']
CSS variables --ocean-1 to --ocean-7 defined in :root, used consistently
booking_reference generated by MySQL trigger automatically
